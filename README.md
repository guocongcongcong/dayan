# 大衍 · 摇卦与解卦

大衍筮法的电子化，单页应用，无构建、无后端、无依赖。

顶部两个标签页：**摇卦** 与 **解卦**。摇完可直接切到解卦，六爻自动带入，不需要重填。

## 流程

```
摇卦 ──→ 本卦 / 变卦 / 动爻 ──→ 解卦
                                  ├ 判辞依据（朱熹七条）
                                  ├ 高岛断语（按问题类别）
                                  ├ 经文（爻辞·小象·彖传·大象）
                                  ├ 爻位（得位·得中·相应）
                                  └ 卦变（互·综·错）
```

想用真蓍草摇的人，也可以在解卦页直接录入六爻。

## 链接直达

| 链接 | 效果 |
|---|---|
| `#auto` | 打开即摇一卦 |
| `#card` | 摇完直接出分享卡片 |
| `#read` | 直接进解卦页 |
| `#l=8,9,7,9,7,7` | 按指定六爻解卦（初爻在前） |

## 摇卦怎么算的

不是"随机抽一个 6/7/8/9"，而是**逐变真模拟**：

```
一变:  左 = 随机 1..n-1        // 分而为二以象两
       右 = n - 左; 右 -= 1     // 挂一以象三
       收 = 1 + (左%4||4) + (右%4||4)   // 揲之以四、归奇于扐
一爻:  n = 49，跑三遍，n/4 → 9/8/7/6
一卦:  跑六遍，初爻在前
```

一变只能收 5 或 9，二三变只能收 4 或 8——这是算法自然的结果。
三变后余 36/32/28/24，除以四得 9/8/7/6。9 老阳、6 老阴为动爻。

点开「十八变明细」，每一变的数字都是真的摇出来的，可以核对。

### 两种模式

| 模式 | 说明 |
|---|---|
| 保真推演（默认） | 逐变真模拟。因 43 个分点除不尽 4 个余数类，「去4:去8」实测 51.1:48.9，老阳约 19.7%（理论 18.75%） |
| 经典概率 | 严格按朱熹 3:5:7:1 定爻，再反推一组自洽的三变数字 |

## 解卦怎么取辞

按朱熹《易学启蒙》七条定主次：

| 动爻数 | 取什么 |
|---|---|
| 0 | 本卦卦辞 |
| 1 | 本卦该动爻爻辞 |
| 2 | 本卦两动爻，以上爻为主 |
| 3 | 本卦卦辞为主、变卦卦辞为辅 |
| 4 | 变卦两不变爻，以下爻为主 |
| 5 | 变卦那个不变爻 |
| 6 | 变卦卦辞（乾用九、坤用六） |

断语取自高岛易断，按其原有的 12 类问题（时运／婚姻／功名／营商／家宅／疾病／失物／讼事／行人／六甲／战征／天时）分段检索，一字不改。
另外展示彖传、小象传、爻位（得位／得中／相应）与互卦／综卦／错卦。

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 全部界面（摇卦 + 解卦两个标签页） |
| `divination.html` | 旧地址，自动跳转到 `index.html#read` |
| `lib/engine.js` | 起卦引擎，纯函数 + `crypto.getRandomValues` 真随机 |
| `lib/card.js` | 摇卦分享卡片（Canvas 1080×1440） |
| `lib/card2.js` | 解卦分享卡片（自适应字号） |
| `data/hexagrams.js` | 64 卦索引（卦名、卦符） |
| `data/iching64.*` | 卦辞、爻辞、大象、高岛易断全文 |
| `data/takashima*.*` | 高岛断语按问题类别的结构化索引 |
| `data/wenyan.*` | 彖传 + 384 条小象传 |
