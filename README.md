# 大衍 · 十八变而成卦

大衍筮法的电子起卦器。不做解卦，只做「摇卦」这一步。

## 它怎么算的

不是"随机抽一个 6/7/8/9"，而是**逐变真模拟**：

```
一变:  左 = 随机 1..n-1        // 分而为二以象两
       右 = n - 左; 右 -= 1     // 挂一以象三
       收 = 1 + (左%4||4) + (右%4||4)   // 揲之以四、归奇于扐
一爻:  n = 49，跑三遍，n/4 → 9/8/7/6
一卦:  跑六遍，初爻在前
```

一变只能收 5 或 9，二三变只能收 4 或 8——这是算法自然的结果。
三变后余 36/32/28/24，除以四得 9/8/7/6。9 老阳、6 老阴为动爻。

点开「十八变明细」，每一变的数字都是真的摇出来的，可以核对。

## 两种模式

| 模式 | 说明 |
|---|---|
| 保真推演（默认） | 逐变真模拟。因 43 个分点除不尽 4 个余数类，「去4:去8」实测 51.1:48.9，老阳约 19.7%（理论 18.75%） |
| 经典概率 | 严格按朱熹 3:5:7:1 定爻，再反推一组自洽的三变数字 |

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 全部界面，无构建、无依赖 |
| `lib/engine.js` | 起卦引擎，纯函数 + `crypto.getRandomValues` 真随机 |
| `data/hexagrams.js` | 64 卦索引（卦名、卦符） |

卦名与卦符属公有领域。代码可自由使用。

## 本地打开

直接用浏览器打开 `index.html` 即可。挂到 https 下「复制」会走 `navigator.clipboard`，`file://` 下退回 `execCommand`。
